# 👗 Garimpo Chic • Brechó

Landing page institucional e promocional do **Garimpo Chic • Brechó**, um espaço de moda consciente e acessível em Palhoça - SC.

## 📌 Sobre o Projeto

Este repositório contém o código-fonte da página web oficial do **Garimpo Chic**, desenvolvida com o objetivo de promover a loja e apresentar a identidade da marca, história, localização física e integrar os canais de atendimento e redes sociais.

* **Desenvolvido por:** Diego Tomaz (Aluno da 1ª Fase do curso de Análise e Desenvolvimento de Sistemas - FMP)
* **Objetivo:** Promover a loja/brechó e aplicar conceitos práticos de desenvolvimento web.
* **Marca:** Garimpo Chic • Brechó
* **Localização:** Palhoça, Santa Catarina (atendimento dentro do *CJ Nails Designer Studio*)
* **Tipo de Projeto:** Web Page / Landing Page Responsiva

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias nativas da web, garantindo leveza e carregamento rápido:

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Estilização com suporte a variáveis CSS (`custom properties`), Flexbox, CSS Grid e media queries para responsividade.
* **Google Fonts:**
  * *Montserrat* (textos corporativos, navegação e botões)
  * *Cormorant Garamond* (títulos e destaques clássicos)
  * *Allura* (detalhes manuscritos e assinaturas)

## 💻 Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/garimpo-chic.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd garimpo-chic
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador ou utilize a extensão **Live Server** no VS Code.
